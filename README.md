## 🚀 Features

| **Feature** | **Description** |
|:---|:---|
| **Modrinth & CurseForge** | Browse and install mods from both platforms directly |
| **Instance System** | Isolated instances for different modpacks and game versions |
| **Multi-Loader** | Fabric, Quilt, Forge, and NeoForge all supported out of the box |
| **Active Development** | Frequent updates and an engaged community of contributors |
